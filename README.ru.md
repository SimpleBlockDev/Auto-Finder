# Auto-Finder (Mod Finder / Auto-Modpacker)

*[English](README.md) · Русский*

Консольная программа для игроков Minecraft, сборщиков модпаков и админов серверов. Она ищет **сразу на Modrinth и CurseForge**, склеивает один и тот же мод с обоих сайтов в одну запись, находит аддоны к моду и собирает готовые модпаки. Чистый Python без зависимостей, работает на Windows, Linux, macOS и в Termux для андроидов.

## Зачем нужен и чем уникален

Порой искать «все аддоны к X» руками приходится часами. Auto-Finder обходит это: собирает кандидатов поиском и проверяет у каждого список зависимостей на нужный мод, включая аддоны аддонов. Он считает обе площадки одним каталогом, выбирает самый новый подходящий файл под твою версию Minecraft и загрузчик и пишет результат в двух видах: подробный отчёт и компактный для нейросети, чтобы тратить меньше токенов и собирать наиболее подходящие моды.

## Самые удобные функции

- **`bulk`**: берёт странички или категории модов(тег или ссылка на категорию любого сайта), ищет аддоны к каждому моду и сохраняет всё в `found_mods/mods.txt` и `found_mods/mods_ai.txt`. Список копится между запусками.
- **`build`**: сборщик модпаков. Даёшь главный мод, получаешь его аддоны по блокам «загрузчик + версия Minecraft» с пометками «эксклюзив» и «нет на», готовые `.jar` в `found_mods/modpacks/` и экспорт `.mrpack`. Один и тот же мод на двух сайтах сопоставляется по хешу файла.
- **`importlink`**: вставляешь ссылки Modrinth/CurseForge (можно просто бросить их в скрипт), он скачивает самый новый файл под твою версию и загрузчик вместе с обязательными зависимостями.
- **`update`**: обновляет моды в папке. Определяет их по SHA1 / отпечатку CurseForge, ищет новее на обоих сайтах, старые файлы убирает в `_old`.

## Как пользоваться

1. Установи Python 3, скачай `Auto-Finder-Public-Release.py` и запусти: `python Auto-Finder-Public-Release.py`.
2. Выбери язык (`ru` / `en`).
3. Для CurseForge получи бесплатный API-ключ на console.curseforge.com и сохрани командой `key <твой ключ>`. Без ключа работает только Modrinth.
4. Вводи команды после `>`. Пример: `search optimization` покажет нумерованный список, `show 3` откроет полную карточку, `save 3` добавит её в твой список.

*Slug* это конец ссылки на мод, например `sodium` в `https://modrinth.com/mod/sodium`.

## Второстепенные функции

- `search <тег | name:название | ссылка>`: поиск по тегам (И), по названию (`name:iron_man`) или по ссылке на категорию.
- `show <N>`, `save <N>`, `saveall`: просмотр и сохранение результатов последнего поиска.
- `addons <slug | modid>`: возможные аддоны одного мода (список неполный, подробности в самой команде).
- `newaddons <ссылка | slug> [период] [загрузчик] [версия]`: новые аддоны за неделю, месяц и т. д.
- Фильтры скачивания: `mr=5k cf=1m` (пропуск модов с малым числом скачиваний), `prefer CF|M`, `only releases`.
- `help` покажет все команды, `exit` выход.
